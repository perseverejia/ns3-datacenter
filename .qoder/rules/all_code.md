# 代码编写规则

## 输出格式要求

写代码时，必须按以下格式输出：

### 1. 列出文件和修改内容

在给出代码前，先列出所有相关的文件及其修改内容，格式如下：

**修改文件：**
- `文件路径1`：修改内容描述
- `文件路径2`：修改内容描述

**新增文件：**
- `文件路径3`：文件用途说明

### 2. 给出代码

按文件逐个给出完整代码或修改后的代码片段。

### 3. 编译运行

- 代码以保证编译成功为准
- 代码以保证运行成功为准

## 禁止事项

- 不要自行分析代码逻辑
- 不要解释实现原理
- 不要提供优化建议
- 不要输出与代码无关的说明
